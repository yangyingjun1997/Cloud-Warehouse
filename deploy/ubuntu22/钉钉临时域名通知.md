# 钉钉临时域名通知

## 创建机器人

建议在仓库管理员群单独创建一个钉钉群机器人，不要和业务审批通知共用。安全设置建议选择“加签”，群关键词可设置为“仓库”。

## 配置 NUC

完成 `cloudflared` 安装并执行以下命令安装 Tunnel 服务文件：

```bash
sudo bash deploy/ubuntu22/enable-quick-tunnel.sh
```

然后运行配置向导：

```bash
sudo /usr/local/sbin/configure-after-sales-warehouse-dingtalk
```

向导会要求填写：

- Tunnel 专用钉钉机器人 Webhook
- 机器人加签密钥；未启用加签可以留空
- 需要被 `@` 的手机号；可留空
- 是否 `@` 全体成员；建议填 `0`

配置保存在：

```text
/etc/after-sales-warehouse/quick-tunnel-dingtalk.env
```

权限为 `root:cloudflared 640`，不应提交到 Git。

## 查询与测试

查询当前临时地址：

```bash
sudo /usr/local/sbin/after-sales-warehouse-quick-tunnel-url
```

发送一条测试消息：

```bash
sudo /usr/local/sbin/after-sales-warehouse-quick-tunnel-dingtalk-test
```

查看 Tunnel 日志：

```bash
sudo journalctl -u after-sales-warehouse-quick-tunnel -f
```

## 自动行为

- NUC 重启且网络恢复后，Tunnel 服务会自动启动。
- 识别到新 `trycloudflare.com` 地址后，自动发送一条钉钉群消息。
- 同一个地址不会重复发送。
- Tunnel 异常重启生成新地址后，会再次发送通知。
- 钉钉发送失败不会停止仓库系统或 Tunnel，只会记录日志。
- 临时域名适合测试和内部试用，不适合作为正式生产域名。
