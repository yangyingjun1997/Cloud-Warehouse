# 售后仓库微信小程序

本目录是与 Django 服务器程序分离的小程序客户端。当前版本复用现有 `/api/` 接口，不复制仓储、审批或权限判断逻辑。

## 已实现范围

- 内部账号密码登录。
- 资产名称、系统资产编码、原厂 SN、原厂条码、别名及拼音首字母检索。
- 调用微信相机或相册扫码，识别系统二维码和外部条码。
- 资产详情、仓库人员拍照上传资产照片。
- 借用、领用、归还申请，包含申请说明、实际使用人、使用单位、联系电话、使用地点和预计归还日期。
- 我的申请与仓库人员待审批/待执行任务分区。
- 申请详情中的审批、驳回（必须填写原因）、出入库确认、撤回和个人记录隐藏。
- 通知点击后标记为已读，并跳转到关联申请详情。

## 开发工具导入

1. 使用微信开发者工具导入本目录 `miniprogram/`。
2. 当前使用的 AppID 为 `wx02c8193db5952f39`，请勿改回 `touristappid`。
3. `project.config.json` 已开启 `urlCheck`；请求、上传和下载合法域名均需在微信公众平台登记。
4. 当前体验版 API 地址为 `https://cloudwarehouse.dpdns.org`，配置在 `miniprogram/utils/config.js`。不要改回 `127.0.0.1` 或内网 HTTP 地址。

## 地址配置

- 当前体验版和真机联调：`https://cloudwarehouse.dpdns.org`
- 同一公司 Wi-Fi 下的 Web 调试仍可使用内网地址，但小程序配置不能使用内网 HTTP 地址。
- 真机预览和正式发布：继续使用已登记的 HTTPS 合法域名；若域名、Tunnel 或服务器不可达，小程序请求会失败。

`127.0.0.1` 仅指向手机或开发工具自身，不能用于真机访问服务器。小程序正式版不能依赖“关闭合法域名校验”；该选项只用于开发工具验收。

## 验收顺序

1. 手机 4G 访问 `https://cloudwarehouse.dpdns.org/health/`，确认返回数据库正常；该检查只证明公网入口可达。
2. 在微信开发者工具中确认 `urlCheck` 开启，使用体验版编译或真机预览。
3. 用现有内部账号登录小程序。
4. 检索或扫码任一在库资产，查看资产详情并提交借用申请。
5. 用仓库人员账号在“待审批与执行”中审核并确认出库。
6. 确认申请人收到通知，点击通知可进入同一申请详情。
7. 用仓库人员账号在资产详情中测试相机拍照上传。
8. 将每项实际结果记录到 `PROJECT_STATUS.md`；未测项目不能标记为通过。

## 当前边界

第一版移动端聚焦现场操作频率最高的资产借用、领用、归还和审批执行。数量耗材、多物品申请、调拨、售出、返修、退货和报废仍保留在 Web 端；在现场流程稳定后，再按实际使用频率扩展到小程序，避免把后台配置界面搬到手机上。
